## Review corrections and common controls

The completed recheck added 12/14/15, strengthened 08 beyond packaging, restored explicit publication modes in 10/11, restored CodeQL extended queries and added the combined 03 selection. Parsed policy now requires exactly one workflow for each number 00–15, resolved job dependencies, full remote-action commit pins, public standard Ubuntu runners, bounded timeouts, non-cancelling concurrency, one-day automatic artifact retention, read-only root permissions and narrowly scoped write jobs. Referenced local composite actions are checked too. Source pin/settings assertions do not prove runner availability, billing eligibility, successful task execution or artifact contents.

Builds keep `-Pmukhtabir.autoVersion=false`, the current wrapper/JDK/SDK selection, isolated module output paths and bounded worker/memory checks. Signing secrets are step-scoped to isolated environment-backed signing jobs with no Gradle/cache execution. Publication and both cleanup definitions are prepared code paths, not permission to run them now. Unknown mutations require inspection before a new explicit attempt; no overwrite/clobber/reset/automatic destructive replay is added.

All workflows remain manual; automatic 09 cleanup, schema/database work, version changes, Android instrumentation/coverage expansion, actual signing/distribution and any build/test/emulator/scanner execution remain outside this source-only recheck. Backend/Vue code remains unchanged; their deferred suggestions stay in the [repository guide](git-and-github.md#deferred-backend-and-vue-work).
