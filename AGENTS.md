# Android: start here

Read [Agents.md](Agents.md) for working rules and verification authorization. Use [README.md](README.md) to select the relevant guide; do not load every guide or old review by default. Inspect the working tree and current production source before trusting a finding.

Ask and receive user approval before creating any new automated test files, including temporary test scripts. Ask the user and receive explicit confirmation before running any build, compilation or packaging command, or extensive tests (including full suites, broad integration/end-to-end runs, or other long-running/resource-heavy checks). State the proposed command and scope before asking; a general implementation/fix request is not confirmation. Reuse confirmation already granted for that scope. Lightweight source checks and relevant existing focused tests are allowed with installed tools/persistent caches. Before building, check for other active builds and high RAM usage; wait/recheck or finish with a manual-build notice if busy. Preflight the toolchain, preserve versions and ask before installing missing requirements. Keep history compact and preserve reusable guidance. Detailed policy: [efficient verification](Agents.md#efficient-verification).
