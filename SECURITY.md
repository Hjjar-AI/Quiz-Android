# Security reporting

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/Hjjar-AI/Quiz-Android/security/advisories/new), if enabled. Otherwise contact the repository owner through the maintainer's published security contact, [hjjarmhmmdali@gmail.com](mailto:hjjarmhmmdali@gmail.com). Do not post sensitive reproduction details in public issues. The email is the same maintainer contact published by Aqaqeer; GitHub private-reporting availability has not been verified here.

Include affected app/server versions, expected and observed behavior, and sanitized reproduction steps. Never attach passwords, session cookies/tokens, connection files, signing keys, private account data or database/offline backups. No response-time commitment is implied.

Development targets matching Android, backend and Vue versions. Preserve existing data and recovery when reporting an incompatibility; see the [compatibility policy](Agents.md#start-and-scope).
